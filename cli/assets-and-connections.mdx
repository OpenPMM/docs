## Upload an asset

The CLI sends the file to a short-lived storage URL. It does not send the API key to that URL.

```bash
openpmm assets upload ./launch.webp \
  --workspace ws_01JABCDEF \
  --json
```

## Check an asset against its destinations

```bash
openpmm assets validate ast_01JABCDEF \
  --workspace ws_01JABCDEF \
  --destination dst_01JABCDEF \
  --json
```

Use `--channel` instead of `--destination` to check the documented provider
limits without a connected account.

## Convert an image before publication

OpenPMM makes a new file that obeys the limits of the given destinations, and
keeps your original. Publishing and scheduling create the file automatically.
Use this command when you want to inspect the file first. See
[Convert media](/guides/convert-media).

```bash
openpmm assets convert ast_01JABCDEF \
  --workspace ws_01JABCDEF \
  --destination dst_01JABCDEF \
  --json

openpmm asset-conversions show rendition_01JABCDEF \
  --workspace ws_01JABCDEF \
  --asset ast_01JABCDEF \
  --json
```

## Download an asset

The CLI refuses to overwrite an existing local file.

```bash
openpmm assets download ast_01JABCDEF \
  --workspace ws_01JABCDEF \
  --output ./launch.webp
```

## Manage destinations

Destinations include provider connection state and publishable targets.

```bash
openpmm destinations list --workspace ws_01JABCDEF --json
openpmm destinations connect --workspace ws_01JABCDEF --provider youtube
openpmm destinations connect --workspace ws_01JABCDEF --provider bluesky --account alice.bsky.social
openpmm destinations sessions show dcs_... --workspace ws_01JABCDEF
openpmm destinations refresh --workspace ws_01JABCDEF
openpmm destinations disconnect dst_... --workspace ws_01JABCDEF --yes
```

Provider consent completes in a browser. The connection command returns its authorization URL.
Bluesky requires `--account` with a handle or DID. Mastodon requires `--instance-origin`.

## Manage Slack notifications

```bash
openpmm slack connect --workspace ws_01JABCDEF
openpmm slack sessions show dcs_... --workspace ws_01JABCDEF
openpmm slack channels --workspace ws_01JABCDEF --json
openpmm slack update --workspace ws_01JABCDEF --slack-channel C0123456789
openpmm slack test --workspace ws_01JABCDEF --yes
openpmm slack disconnect --workspace ws_01JABCDEF --yes
```

Sending a test and disconnecting Slack require `--yes`.

This guide makes a read-only request. It does not publish content.

## Before you begin

You need an OpenPMM account with access to a workspace. Sign in at [app.openpmm.com](https://app.openpmm.com).

<Steps>
  <Step title="Create an API key">
    Open your workspace, then go to **Workspace settings** and select **API keys**.
    Create a key and copy it immediately. OpenPMM shows the secret once and stores only a hash.
  </Step>
  <Step title="Copy your workspace ID">
    Copy the **Workspace ID** shown on the same page. Keep it next to the key in your local secret manager.
  </Step>
  <Step title="Set local environment variables">
    Use the names below in your shell. Do not commit either value.

    ```bash
    export OPENPMM_API_KEY="your_api_key"
    export OPENPMM_WORKSPACE_ID="your_workspace_id"
    ```
  </Step>
  <Step title="Verify the credential">
    Request the identity attached to the key.

    ```bash
    curl --request GET \
      --url https://api.openpmm.com/v1/me \
      --header "Authorization: Bearer $OPENPMM_API_KEY"
    ```

    A successful response identifies the credential, its environment, access mode, and scopes.
  </Step>
  <Step title="List destinations">
    Check which connected social accounts are available.

    ```bash
    curl --request GET \
      --url "https://api.openpmm.com/v1/workspaces/$OPENPMM_WORKSPACE_ID/destinations" \
      --header "Authorization: Bearer $OPENPMM_API_KEY"
    ```
  </Step>
</Steps>

<Warning>
  Treat an API key like a password. Keep production keys in your deployment platform's secret store, never in source control or client-side code.
</Warning>

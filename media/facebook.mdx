Facebook has two placements, and each placement has its own media rules. Set `placement` in the Facebook post options. Read [Media guidelines](/media/overview) for the general rules.

## Media per post

| Placement | Media |
| --- | --- |
| `reel` | Exactly one video |
| `feed` | Up to 10 images |

A Facebook feed post accepts images only.

## Reel video limits

| Property | Limit |
| --- | --- |
| Duration | 4 to 60 seconds |
| Frame rate | 23 to 60 fps |
| Width | 540 px minimum |
| Height | 960 px minimum |
| Aspect ratio | 9:16 |
| File size | 500 MiB |

<Note>
  OpenPMM applies these limits when `placement` is `reel`. Select the placement before you validate the post. A different placement has a different contract, and OpenPMM cannot apply the Reel limits to it.
</Note>

## Images

OpenPMM accepts a PNG, JPEG, WebP, or GIF image up to 500 MiB. Facebook has no additional image limit in OpenPMM.

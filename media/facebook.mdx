Facebook has two placements. OpenPMM selects the placement from the attached media. Read [Media guidelines](/media/overview) for the general rules.

## Media per post

| Placement | Media |
| --- | --- |
| `reel` | Exactly one video |
| `feed` | Up to 10 images |

A Post with one video uses the `reel` placement automatically. A Post with images uses the `feed` placement.

## Reel video limits

| Property | Limit |
| --- | --- |
| Duration | 4 to 60 seconds |
| Frame rate | 23 to 60 fps |
| Width | 540 px minimum |
| Height | 960 px minimum |
| Aspect ratio | 9:16 |
| File size | 500 MiB |

<Note>
  You can omit the Facebook post options. If you send `feed` with one video, OpenPMM changes the placement to `reel`.
</Note>

## Image limits

| Property | Limit |
| --- | --- |
| Format | JPEG, PNG, or GIF |
| File size | 4 MB maximum |

Facebook can make a PNG above 1 MB look pixelated. OpenPMM gives advice for
this, but it does not block the post.

Facebook documents no dimension limit and no aspect ratio limit for an image.
Facebook makes an image smaller itself and removes the location metadata.

OpenPMM converts a WebP image and makes the file smaller when it is above 4 MB.
See [Media compatibility](/guides/media-compatibility).

X accepts a short video with strict dimensions. Read [Media guidelines](/media/overview) for the general rules.

## Media per post

An X post accepts up to four assets.

## Video limits

| Property | Limit |
| --- | --- |
| Duration | 0.5 to 140 seconds |
| File size | 500 MiB. X permits 512 MB, but the OpenPMM limit is lower. |
| Width | 32 to 1,280 px |
| Height | 32 to 1,024 px |
| Aspect ratio | 1:3 to 3:1 |
| Frame rate | 60 fps maximum |
| Pixel shape | Square pixels. The sample aspect ratio must be 1:1. |
| Pixel format | YUV 4:2:0 |
| Scan type | Progressive |
| Audio codec | AAC |
| Audio channels | Mono or stereo |

X recommends the H.264 video codec. OpenPMM gives advice for a different codec, but it does not block the post.

## Images

OpenPMM accepts a PNG, JPEG, WebP, or GIF image up to 500 MiB. X has no additional image limit in OpenPMM.

## Limits that OpenPMM cannot check

X documents a closed group of pictures (GOP). OpenPMM cannot read this property from the file. Make sure that your encoder writes a closed GOP.

LinkedIn accepts one video or a set of images. Read [Media guidelines](/media/overview) for the general rules.

## Media per post

- One video, or
- up to 20 images.

LinkedIn does not accept a video and an image in the same post.

## Video limits

| Property | Limit |
| --- | --- |
| File type | MP4 |
| File size | 75 KiB to 500 MiB |
| Duration | 3 seconds to 30 minutes |

LinkedIn documents other encoding values as advice. OpenPMM does not block the post for these values.

## Image limits

| Property | Limit |
| --- | --- |
| File types | JPEG, PNG, or GIF |
| Pixel count | Less than 36,152,320 pixels. Multiply the width by the height. |
| Animated GIF frames | 250 maximum |

LinkedIn documents no file size limit for an image. OpenPMM cannot check a
limit that the provider does not document.

LinkedIn does not accept a WebP image. OpenPMM converts a WebP image, and makes
an image smaller when it has too many pixels. See
[Media compatibility](/guides/media-compatibility).

---
title: "Upload assets"
description: "Upload a media file and add it to a post."
---

OpenPMM uses three steps to upload a file. Create an upload, send the file to the returned URL, and complete the upload.

<Steps>
  <Step title="Begin the upload">
    Send the file data. Use the exact byte size and media type.

    ```json
    {
      "kind": "card",
      "file_name": "launch-card.png",
      "content_type": "image/png",
      "byte_size": 248031
    }
    ```
  </Step>
  <Step title="Upload the bytes">
    Send the file to `upload_url`. Include all values from `required_headers`. Do not send the OpenPMM API key to this URL.
  </Step>
  <Step title="Complete the upload">
    Call `POST /workspaces/{workspace_id}/asset-uploads/{upload_id}/complete`. This request does not have a JSON body. OpenPMM checks the file and returns the asset.
  </Step>
</Steps>

Store the returned asset `id`. Add the ID to the post `media` array.

## Validate a video

Validate an uploaded video before you publish it. Send destination identifiers
to include current destination limits. Send channel names when you only need
static provider limits.

```json
{
  "destination_ids": ["dst_01JABCDEF"]
}
```

Call `POST /workspaces/{workspace_id}/assets/{asset_id}/video-validations`.
The response lists each unmet requirement. Each issue includes the actual
value, required value, rule owner, and suggested action. A blocking issue stops
publication to the affected destination.

OpenPMM keeps the original video. Phase 1 does not convert the video.

<Warning>
  The upload URL expires at `expires_at`. Create a new upload after this time.
</Warning>

## How it works

<Steps>
  <Step title="Get your API key">
    Sign up for an Open PMM account and navigate to **Settings → API Keys** to generate your first key. You'll use this key to authenticate every request you make to the API.
  </Step>
  <Step title="Make your first call">
    Pass your key as a Bearer token in the `Authorization` header and hit any endpoint. Start with `GET /v1/resources` to list your products and features — you'll have a live response in seconds.
  </Step>
  <Step title="Explore features">
    Dig into metrics ingestion, event streaming, webhook subscriptions, and the forthcoming CLI for agent-driven workflows. The full surface area of Open PMM is available from day one.
  </Step>
</Steps>

<Note>
  Looking for the complete endpoint catalogue? Head to the **API Reference** tab in the top navigation for full request/response documentation on every route Open PMM exposes.
</Note>

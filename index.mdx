OpenPMM gives your software one API for publishing to the social accounts you already own.
You connect a destination once, then create, schedule, and inspect posts without implementing each provider separately.

<Note>
  OpenPMM is in limited access. The documented API is the public contract for available accounts. Features that are still in development are not included here.
</Note>

## The OpenPMM model

Every API key belongs to one **workspace**. A workspace contains **destinations**, which are the connected social accounts that can receive content. A **post** describes the content for one destination. Confirming one or more posts creates a **send**, the durable record of a publishing attempt.

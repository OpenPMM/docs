### v0.1.0 — Initial Release

**Released:** 2025-01-01

This is the first public release of the Open PMM API. It establishes the foundational surface area for product management and metrics workflows.

- **Resources CRUD endpoints** — Create, read, update, and delete product resources via `/v1/resources`.
- **Metrics recording endpoint** — Record quantitative product metrics against any resource via `/v1/metrics`.
- **Events ingestion endpoint** — Ingest arbitrary product events with structured payloads via `/v1/events`.
- **Webhook registration and delivery** — Register HTTPS endpoints to receive real-time event notifications; deliveries are signed with HMAC-SHA256 via `/v1/webhooks`.
- **Cursor-based pagination** — All list endpoints return `next_cursor` and `has_more` fields for reliable, stateless pagination.
- **Bearer token authentication** — All requests authenticate via the `Authorization: Bearer <key>` header. API keys are created and managed in the dashboard.
